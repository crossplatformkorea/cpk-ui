## Set up

Install the package with its peers. kstyled's runtime and Babel plugin must be
on the same version.

```bash
npx expo install cpk-ui@0.8.0 kstyled@0.4.1 @expo/vector-icons \
  react-native-gesture-handler react-native-svg expo-screen-orientation \
  react-native-reanimated react-native-worklets @shopify/flash-list \
  @expo/match-media expo-haptics
bun add --dev babel-plugin-kstyled@0.4.1
```

Put kstyled first in your Babel plugins and Reanimated last.

```js
module.exports = {
  presets: ['babel-preset-expo'],
  plugins: [
    ['babel-plugin-kstyled', {strict: true}],
    'react-native-reanimated/plugin',
  ],
};
```

Wrap the app once. `CpkProvider` loads Pretendard and supplies the light and
dark tokens.

```tsx
import {CpkProvider} from 'cpk-ui';

export function App() {
  return <CpkProvider>{/* your screens */}</CpkProvider>;
}
```

Use the theme switch in the toolbar to check every story in light and dark,
and the viewport menu for phone, tablet and desktop widths.
