# cpk-ui 0.8.0 beta 0

This beta adds the two shared surfaces needed by calendar-led applications:
an accessible Calendar and a list-agnostic ParallaxHeader. Both use one API on
iOS, Android, and web and keep product routing, data fetching, and date storage
outside the package.

## Install

```bash
npx expo install cpk-ui@0.8.0-beta.0 kstyled@0.4.1 \
  react-native-gesture-handler react-native-reanimated
bun add --dev babel-plugin-kstyled@0.4.1
```

## Highlights

- Calendar selection, visible page, markers, disabled dates, locale, week
  start, responsive size, and month/week mode can all be controlled.
- Calendar day markers are keyed by `yyyy-MM-dd`, so cells do constant-time
  lookup and hosts can supply a business-timezone day without a date library
  dependency in cpk-ui.
- ParallaxHeader accepts a shared scroll offset from any Reanimated-compatible
  scroll container. Header layout height stays fixed; only transform and
  opacity change during scroll.
- Persistent navigation, expanded presentation, and compact presentation use
  separate slots, so product actions remain mounted while titles cross-fade.

## Migration

No existing component was removed. Applications using Calendar or
ParallaxHeader must have Expo-compatible Reanimated installed and configured.
Pass a memoized marker map to Calendar, and add list content top padding equal
to ParallaxHeader's expanded height.
