# cpk-ui 0.8.0 beta 1

This beta adds a controlled AlertDialog API for forms that must stay mounted,
and tightens text-button padding so labels hug their hit target with a real
pressed underlay.

## Install

```bash
npx expo install cpk-ui@0.8.0-beta.1 kstyled@0.4.1 \
  react-native-gesture-handler react-native-reanimated
bun add --dev babel-plugin-kstyled@0.4.1
```

## Highlights

- AlertDialog accepts `visible` and `onClose` so hosts can keep a dialog
  mounted across frequent re-renders. Imperative `open()` is a no-op while
  `visible` is controlled.
- The title sits on the same row as the close control. `closeOnTouchOutside`
  can lock outside taps for blocking flows such as required onboarding.
- Text buttons use `8px 16px` padding, hug their label, keep a visible
  pressed underlay, and do not fill a solid disabled surface.

## Migration

Uncontrolled `AlertDialog.open()` / `close()` still works. Hosts that need a
live form inside the dialog should pass `visible` and `onClose` instead of
re-opening on every render. Button `style` still omits `borderRadius` and
`padding`; pass `borderRadius` as a prop.
