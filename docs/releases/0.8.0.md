# cpk-ui 0.8.0

The first stable 0.8 release promotes 0.8.0-beta.0 through 0.8.0-beta.7 and
adds `DonutChart`, `LineChart` and `SelectionFeedback`.

## Install

```bash
npx expo install cpk-ui@0.8.0 kstyled@0.4.1 @expo/vector-icons \
  react-native-gesture-handler react-native-svg expo-screen-orientation \
  react-native-reanimated react-native-worklets @shopify/flash-list \
  @expo/match-media expo-haptics
bun add --dev babel-plugin-kstyled@0.4.1
```

## Highlights

- Charts: `DonutChart` and `LineChart` draw with `react-native-svg`, which is
  now a declared peer dependency (>=15).
- Motion: `SelectionFeedback` pops deliberate selections. `Calendar` opts in
  with `selectionAnimation`; `RadioButton` uses it by default.
- New since 0.7: `Calendar`, `ParallaxHeader`, `PageIndicator`,
  `ReorderableList`, `TimePicker`, controlled `AlertDialog` and `Accordion`.
- iOS wraps Korean at word boundaries by default; `AlertDialog` avoids the
  Android keyboard.

## Migration from 0.7

- Install the new peers: `react-native-svg`, `react-native-worklets` and
  `@shopify/flash-list` (FlashList 2 requires the New Architecture), with
  React 19 and Reanimated 4.
- `RadioButton` animates selection by default; pass
  `selectionAnimation={false}` to keep it static.
- Text buttons pad `8px 16px` and hug their label. `Button` `style` still
  omits `borderRadius` and `padding`; pass `borderRadius` as a prop.
- Hosts that keep a live form in `AlertDialog` should pass `visible` and
  `onClose`.
